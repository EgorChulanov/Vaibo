> Это рабочий чек-лист, а не юридическое заключение. Документы на сайте описывают, как приложение работает сейчас (по `ACTIVE_GOAL.md` и `APPLE_SIGN_IN.md` от 14.09.2026). Перед публикацией их нужно один раз показать юристу по IT и персональным данным. Пока неизвестны юрлицо, сервер и реальные процессы, называть Vaibo «соответствующим 152-ФЗ» нельзя.

## 1. Домен vaibofood.ru

**Сейчас домен не откроется.** В reg.ru висит «Ошибка при идентификации». Для доменов .ru администратор обязан подтвердить личность через Госуслуги, иначе домен не делегируется.

1. reg.ru → домен → «Узнать подробнее» → повторить идентификацию через Госуслуги.
2. ФИО и паспорт в профиле reg.ru должны совпадать с Госуслугами буква в букву (частая ошибка: «е» вместо «ё», старый паспорт).
3. Не получается — написать в поддержку reg.ru со скриншотом.

### DNS для GitHub Pages

reg.ru → «DNS-серверы и управление зоной» (оставить ns1.reg.ru / ns2.reg.ru) → ресурсные записи:

| Тип | Имя | Значение |
|---|---|---|
| A | @ | 185.199.108.153 |
| A | @ | 185.199.109.153 |
| A | @ | 185.199.110.153 |
| A | @ | 185.199.111.153 |
| CNAME | www | egorchulanov.github.io. |

GitHub → Settings → Pages: Source **GitHub Actions**, Custom domain `vaibofood.ru`, после выпуска сертификата **Enforce HTTPS**.

Сайт не ставит cookies, не подключает счётчики, а шрифт Onest лежит на нашем же сервере. Поэтому на GitHub Pages он не собирает персональные данные. Если появятся формы или Метрика, сайт лучше переехать на российский хостинг: папка `site/` переносится как есть.

## 2. Главный блокер: где лежат данные приложения

В приложении есть аккаунт (Sign in with Apple), согласия, пищевой профиль и выгрузка данных через Supabase. **У облачного Supabase нет региона в России.** А ч. 5 ст. 18 152-ФЗ требует, чтобы запись, хранение и обновление данных граждан РФ шли в базах на территории России.

Варианты:

| Вариант | Плюсы | Минусы |
|---|---|---|
| Self-hosted Supabase в Yandex Cloud или Selectel (регион Москва) | тот же код, RLS и миграции | бэкапы, обновления и мониторинг на вас; часть облачных функций недоступна |
| Managed PostgreSQL в Yandex Cloud + свой API | надёжные бэкапы от провайдера | переписать auth и edge-функции |

Пока сервер не в России, держать production-данные россиян в облачном Supabase нельзя. В политике на сайте место под хостинг помечено жёлтым.

## 3. Что проверить юристу (по реальному поведению приложения)

- [ ] **Уведомление Роскомнадзора** об обработке ПДн до запуска (pd.rkn.gov.ru или Госуслуги). Номер из реестра вписать в политику.
- [ ] **Аллергены.** Сейчас это «исключить продукт», без связи с болезнями, и под отдельным согласием. Нужно подтвердить, что это не специальная категория (сведения о здоровье). Если юрист скажет, что специальная, нужна письменная форма согласия (ст. 10 152-ФЗ).
- [ ] **HealthKit.** В заметке про Sign in with Apple упомянут HealthKit в provisioning. Если приложение читает или пишет данные «Здоровья», это уже точно данные о здоровье: отдельное согласие, описание в политике, правила Apple 5.1.3. Если HealthKit не используется, убрать его из entitlements.
- [ ] **Согласия раздельно** (с 1 сентября 2025): аккаунт, пищевой профиль, геопозиция. Ни одна галочка не стоит заранее. Так уже сделано в онбординге, проверить тексты.
- [ ] **Геопозиция** используется на iPhone только для выбора города. Если координаты когда-нибудь начнут уходить на сервер, обновить политику.
- [ ] **ВкусВилл.** Использование открытого MCP для коммерческого приложения, показ фото и текстов рецептов, лимиты запросов. Нужен письменный ответ или договор с ВкусВиллом до релиза.
- [ ] **Контент Food.ru / X5** не использовать без согласования (они прямо просят согласовывать).
- [ ] **Рекомендательные технологии** (ст. 10.2-2 149-ФЗ). Подбор рецептов по профилю может подпадать. На сайте есть раздел «Как подбираются рецепты» в соглашении, юристу решить, нужен ли отдельный документ.
- [ ] **Сведения о продавце** на сайте (Закон о защите прав потребителей): страница контактов и реквизитов.
- [ ] **Товарный знак Vaibo** в Роспатенте: классы 9, 35, 42 и, по совету патентного поверенного, 43/44.
- [ ] **Реклама** в интернете маркируется через ОРД (токен erid).

## 5. Реестры, льготы и поддержка

### Свидетельство на программу в Роспатенте

Даёт подтверждённое право на код, нужно для реестра российского ПО и полезно для грантов.

1. Правообладатель: ООО (или авторы, если ООО ещё нет; потом права можно передать по договору).
2. Подготовить: заявление, реферат (описание программы до 900 знаков), фрагмент исходного кода (обычно первые и последние 25 страниц, можно без коммерческих секретов) в PDF/A.
3. Подать через сайт Роспатента или Госуслуги, оплатить госпошлину по ст. 333.35 НК РФ. Сумма зависит от того, кто заявитель; точную смотрите в калькуляторе на сайте Роспатента перед подачей.
4. Ждать около двух-трёх месяцев. Свидетельство приходит в электронном виде.

### Как у конкурентов

| Что | Где | Что даёт | Требования |
|---|---|---|---|
| Московский инновационный кластер | i.moscow | городская платформа для стартапов: конкурсы, пилоты с городом, гранты, льготная аренда, витрина для инвесторов | регистрация компании или ИП, связь с Москвой |
| Реестр стартапов и высокотехнологичных компаний Москвы | заявка на i.moscow | статус для городских программ и акселераторов | критерии меняются, проверить на i.moscow перед подачей |
| Аккредитация Минцифры | Госуслуги | взносы 7,6%, налог на прибыль 0%, отсрочка от армии для сотрудников, IT-ипотека | только ООО; основная доля выручки от IT; зарплаты не ниже средней по региону; иностранная доля не больше 50%; подтверждать каждый год |

### Сверх того

| Что | Что даёт |
|---|---|
| **Реестр российского ПО** (reestr.digital.gov.ru) | статус отечественного ПО, без НДС на лицензии, сильнее позиция в переговорах с ритейлом. Нужны права на код (свидетельство) и ООО |
| **Фонд содействия инновациям** (fasie.ru): «Студенческий стартап», «Старт» | безвозвратные гранты на первую версию. «Студстартап» подходит, если в команде есть студент |
| **Сколково** | гранты, налоговые льготы, дополнительные баллы в конкурсах ФСИ. Нужна инновационная часть: AR-пергамент и подбор под бюджет подходят |
| **МСП.РФ и «Малый бизнес Москвы»** (mbm.mos.ru) | льготные займы, консультации, компенсация части затрат на патенты |
| **Акселераторы** ФРИИ и программы ритейлеров | деньги, менторы и пилоты с магазинами, что важно для корзин |

### Порядок

1. ООО → уведомление в Роскомнадзор → заявка на товарный знак.
2. Сервер в России (раздел 2) → публикация в App Store.
3. i.moscow → реестр стартапов Москвы → гранты ФСИ.
4. Свидетельство на программу → реестр российского ПО.
5. Выручка и сотрудники → аккредитация Минцифры, Сколково.
6. Плашки в подвал сайта ставить только после того, как статус получен.

## 7. Где лежит код приложения

Код iOS-приложения сейчас на Mac (`/Users/egorchulanov/Desktop/Vaibo`), в этом репозитории только сайт. Чтобы перенести приложение сюда:

```bash
cd ~/Desktop/Vaibo
git remote add origin https://github.com/EgorChulanov/Vaibo.git   # если remote ещё нет
git fetch origin
git checkout -b app
git push -u origin app
```

Перед пушем проверьте, что в репозитории нет `.env`, ключей Supabase service-role, GigaChat, Apple `.p8` и `xcconfig` с секретами.
